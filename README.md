# 📊 Superstore Profitability Analysis

## Project Overview
This project analyzes the Sample Superstore dataset using Microsoft Excel to identify profitable and loss-making areas of the business. The objective is to generate business insights and recommendations that can help improve profitability and support data-driven decision-making.

## Business Problem
The superstore wants to understand:

- Which product categories generate the highest profit?
- Which sub-categories are causing losses?
- Which areas should be prioritized for future growth?
- What actions can improve overall profitability?

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting

## Dataset

- Sample Superstore Dataset

## Key Insights

- Technology generated the highest profit.
- Furniture showed lower profitability despite good sales.
- Tables and Bookcases were among the major loss-making sub-categories.
- Office Supplies delivered stable profits.

## Business Recommendations

- Increase focus on Technology products.
- Review pricing and discounts for Furniture.
- Reduce losses from Tables and Bookcases.
- Improve inventory planning for low-profit products.
