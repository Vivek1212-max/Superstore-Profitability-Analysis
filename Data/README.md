# Data

This folder contains the dataset used for the **Superstore Profitability Analysis** project.

## Dataset

- **File:** Sample - Superstore.csv
- **Format:** CSV
- **Source:** Sample Superstore Dataset

## Description

The dataset includes information about:

- Orders
- Customers
- Products
- Categories and Sub-categories
- Sales
- Profit
- Discounts
- Regions
- Shipping Details

This dataset was used to perform data cleaning, pivot table analysis, and generate business insights using Microsoft Excel.
