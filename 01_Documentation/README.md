# Introduction

## Project Overview

The **Superstore Profitability Analysis** project aims to analyze retail sales data using Microsoft Excel and generate actionable business insights to improve profitability.

This project focuses on identifying high-performing and low-performing product categories, understanding sales trends, and providing data-driven recommendations for business growth.

---

## Objectives

- Analyze sales and profit performance.
- Identify profitable and loss-making categories.
- Perform category-wise and sub-category analysis.
- Create interactive dashboards using Microsoft Excel.
- Support business decisions with data-driven insights.

---

## Business Problem

A retail superstore wants to understand which products, categories, and business areas contribute the most to profit and which require improvement. This analysis helps management make informed decisions to increase revenue and profitability.

---

## Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- GitHub

---

## Outcome

The project demonstrates practical Business Analyst skills, including data analysis, dashboard creation, business insight generation, and presentation of recommendations.
