# Excel Analysis

This folder contains the Microsoft Excel workbook used for the **Superstore Profitability Analysis** project.

## File

- **Superstore Sales Analysis.xlsx**

## Analysis Performed

- Data Cleaning
- Data Validation
- Pivot Tables
- Pivot Charts
- Sales Analysis
- Profit Analysis
- Category-wise Analysis
- Sub-category Performance Analysis
- Business Insights

## Key Findings

- Technology generated the highest profit.
- Furniture had lower profitability despite strong sales.
- Tables and Bookcases were among the major loss-making sub-categories.
- Business recommendations were developed based on the analysis.

## Tool Used

- Microsoft Excel
